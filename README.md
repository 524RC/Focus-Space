# Focus Space

Focus Space is a personal AI-assisted study and productivity web application that I created to help organize my coursework, notes, assignments, and study materials.

## Features

- Class and note organization
- Rich-text note editor
- Task management
- Calendar scheduling
- File importing and exporting
- Light and dark mode
- Note sharing and comments
- AI-powered note summarization
- AI-generated study questions
- Contextual AI question answering

## AI Integration

Focus Space integrates the Google Gemini API to provide AI-powered study tools.

Users can summarize their notes, generate study questions based on their study material, and ask questions about individual notes.

The Ask AI feature also includes an option that allows users to choose whether the AI should only use information contained in their notes or use outside knowledge as well.

## Technologies

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- Google Gemini API

## Project Status

Focus Space is currently a prototype and is still under development. Future plans include adding user authentication and profiles so multiple users can securely manage their own information.
